# DarkRelay

Free, local-first software for Windows and Android.
No telemetry. No accounts. No cloud. Just useful buttons.

*local-first • low-drama • useful buttons*

---

## Programs

### Lazarus PDF
A free, local PDF reader and editor for Windows, with OCR. Open source (AGPL-3.0), no telemetry.

[Download](https://github.com/Crazy8697/LazarusPDF/releases/latest) · [Source](https://github.com/Crazy8697/LazarusPDF)

### PhoneDeck
Run your Android phone's apps in windows on your PC. Free, local, built on scrcpy.

[Download](https://github.com/Crazy8697/PhoneDeck/releases/latest) · [Source](https://github.com/Crazy8697/PhoneDeck)

### Playlist Flow
A free, local-first Windows program that orders your Spotify playlists by key and tempo. Works with Spotify.

[Download](https://github.com/Crazy8697/PlaylistFlow/releases/latest) · [Source](https://github.com/Crazy8697/PlaylistFlow)

### MicroDeck *(coming soon)*
Turns your Android phone into a magnifier for soldering and fine work, with a grid overlay. Free, open source, no telemetry.

[Source](https://github.com/Crazy8697/MicroDeck)
